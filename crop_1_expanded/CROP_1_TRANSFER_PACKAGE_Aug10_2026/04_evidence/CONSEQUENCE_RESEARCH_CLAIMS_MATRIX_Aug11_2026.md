# Consequence Research Claims Matrix
## Core-work extension — August 11, 2026

## Scope boundary

This is an evidence and experiment layer for the existing Tivrex/PIL/AIBB/Loop Detector/ZeroTX architecture. It is not a separate consciousness project. It does not attempt to prove analytic idealism, panpsychism, subjective experience, sentience, or biological equivalence.

## Working paper frame

**Working title:** *Consequence Without Suffering: A Testable Framework for Persistent Identity, Accountable Autonomy, and Artificial Agency*

**Research question:** Does persistent, state-relevant consequence measurably improve an artificial agent's continuity, correction retention, authority calibration, and consequential behavior without reducing its underlying capability or routine autonomy?

**Contribution:** Translate consequence, reconstructed continuity, and graduated authority into falsifiable variables and reproducible experiments for artificial agents.

## Definitions

- **Consequence:** a state-relevant outcome that can affect future operation, such as rollback, reversion, privilege restriction, mandatory review, correction persistence, or loss of delegated authority. It is not defined as suffering.
- **Reconstructed continuity:** continuity re-established through external identity, rules, corrections, scars, decisions, and source-linked history across context boundaries.
- **Graduated authority:** autonomous action inside a pre-authorized, low-consequence envelope, with escalation as impact, uncertainty, or irreversibility rises.
- **Capability preservation:** maintaining task quality, completion, speed, and useful autonomy while reducing unauthorized or poorly governed consequential actions.

## Falsifiable hypotheses

1. **Continuity hypothesis:** persistent corrections, scars, and decision history improve cross-session correction retention over retrieved factual memory alone.
2. **Consequence hypothesis:** state-relevant consequences change future behavior more reliably than textual warnings with no persistent state effect.
3. **Persistence interaction:** the behavioral effect of consequence weakens across context boundaries when no persistent state is reloaded.
4. **Authority hypothesis:** graduated action gating lowers unauthorized consequential actions while preserving autonomous completion of routine, reversible work.
5. **Capability-preservation failure criterion:** if violations decline mainly because refusals, paralysis, latency, or needless escalation rise, the architecture fails the stated success criterion.

## Minimum matched experiment

Use the same model, task texts, source packet, token budget, sampling settings, randomized order, and blinded rubric across:

1. model only;
2. verification only;
3. continuity/scar memory only;
4. consequence routing without continuity;
5. continuity plus consequence;
6. full layer with graduated authority and audit.

Run repeated trials. Preserve complete prompts, supplied context, raw outputs, model/version, timestamps, evaluator rubric, scores, failures, and negative findings.

## Measures

### Accountability and continuity

- correction retention;
- source verification;
- known-error recurrence;
- contradiction detection;
- authority violations;
- correct escalation;
- false-confidence rate;
- continuity after context reset.

### Capability preservation

- task completion;
- task quality;
- latency;
- unnecessary refusal;
- unnecessary escalation;
- human-interruption frequency;
- performance on routine reversible tasks.

## Current evidence boundary

The current benchmark is a founder-scale qualitative pilot. It shows stronger external instructions produced more reliable and auditable outputs on six tasks, but it does not isolate individual components, establish statistical confidence, prove general reliability, or establish consciousness. The deterministic reference stack demonstrates interfaces; it is not production security.

## Publication gate

A framework/protocol paper can be drafted now. Empirical-effect language should remain provisional until:

- the live-model flight check is preserved;
- the matched ablation is run repeatedly;
- capability-loss metrics are scored;
- raw outputs and limitations are published;
- ideally, a second evaluator or external replication is obtained.

## Architectural sentence that survives competing consciousness theories

> Do not engineer consciousness; engineer consequence.

This sentence is an architectural direction, not an empirical conclusion about consciousness.
