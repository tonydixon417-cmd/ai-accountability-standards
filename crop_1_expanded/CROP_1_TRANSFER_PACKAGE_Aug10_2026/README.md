# Tivrex Crop #1 Transfer Package

## Purpose

This package is a bounded transfer and diligence package for an engineering-capable implementation partner or strategic acquirer.

Tivrex supplies an accountability and continuity operating layer. The buyer supplies production engineering, domain integration, security operations, deployment, compliance work, customer onboarding, and distribution.

This is not a finished medical, legal, financial, aviation, or government application. It is not hosted SaaS, consulting, implementation, support, or a model-weight modification.

## Package contents

- `01_orientation/` — buyer definition, transfer brief, partner kit, implementation status, and roadmap.
- `02_architecture/` — AIBB, PIL, Loop Detector, ZeroTX, retrieval, portability, and attribution documents.
- `03_reference_stack/` — the public v2.4.0 reference baseline plus a clearly identified local post-release flight-check extension.
- `04_evidence/` — release parity, evidence ledger, benchmark scorecard, and consequence research claims matrix.
- `05_evaluation/` — unchanged raw C0–C3 benchmark outputs and persistent flight-check evidence.

## Evidence boundary

The benchmark scorecard reports 43/48 points across 24 unchanged outputs. It supports a narrow claim about this live six-task comparison: progressively stronger external instruction and boundary layers produced more reliable, more auditable outputs than the model-only condition.

It does not prove general reliability, production readiness, legal compliance, medical safety, enterprise effectiveness, hallucination elimination, or consciousness. A matched component-level ablation and capability-preservation test remain future work.

The live-model flight check also remains open until a provider API token is supplied securely. The completed dry run made no model network call and sent no external message.
